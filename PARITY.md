# Recreation parity and evidence

## Observed reference

The private primary-reference session observed PDF Expert 3.13.4 build 1177 with an authored three-page synthetic PDF on macOS 27.0.1. Captures established the dark reader chrome, compact top command rows, left thumbnail navigation, page overview, and right-side search result navigation. Highlight selection surfaced a sign-in gate before an annotation was created. Private screenshots/AX are intentionally excluded from this public source export.

## This implementation

The recreated source composes AppKit/PDFKit with the shared Paperwork Core. The reader, optional page-thumbnail sidebar, paged navigation-only overview, and paginated local search navigation are implemented. Result rows include a page number, per-page match count and selected-text snippet. Core-supported operations retain their original behavior and limits. The replica does not include vendor branding, upsell, trial/account flow, or services.

## Unverified and remaining

The 24 October 2026 source snapshot compiled, passed 36 tests, and produced a strict-signature local package. On macOS 27.0.1, exact executable `91780663410660d353e96c4950e0cbed32f74b89f5307723f111593c924622cd` opened the three-page fixture, navigated to page 2, searched for BRAVO, showed the navigation-only overview, and returned to the reader. In retained 25 October captures, the old executable showed no main-area overview cards. The previously built `de63…` candidate changed the overview to a flipped stack, but its overview showed only two page previews with page buttons clipped at the top; page 3 appeared in AX but not as a visible card. The earlier defect and candidate disposition are recorded in [Issue3](https://github.com/Ghostzy0/pip-paperwork-replica/issues/3). Private reference/evaluation captures are excluded from the export.

The current implementation uses an explicit flipped scroll document, with fixed-size preview/button slots and at most 24 pages per batch. Native review of matching executable `c7787a90c1f02085df4247c6bd102bf371a077afd6d2ddadab78831df854f62a` on macOS 27.0.1 found all three complete previews/labels on the same authored fixture. Page 3 reader/return passed. An authored 26-page fixture also passed horizontal scrolling through the first 24 cards, the next 25–26 batch, and Page 26 reader/return. Eight retained overview JPEG/AX pairs were inspected independently; source hashes stayed unchanged and teardown was verified. A later native I/O slice on the same package passed synthetic field edit/save/reopen, invalid-PDF error with current-copy retention, native picker cancellation, and Page 2/BRAVO search with one result. Ten retained JPEG captures from that I/O slice were independently reviewed; the source input stayed unchanged and teardown was verified. The older clipped candidates remain rejected visual fixes. See [TESTING.md](TESTING.md) for source identity and the remaining cases.

This is bounded evidence on selected authored inputs and the captured viewport. One resize attempt did not reduce the window; native-point size and minimum-window behavior remain unestablished. Keyboard-only, VoiceOver and macOS 14 GUI checks remain unverified. Broader forms, text-selection markup creation, save/export, and OCR behavior remain unverified against the commercial reference because its relevant free path was gated. The implementation deliberately has one active document. It does not provide the observed Bookmarks, Outline or Annotation Summary panes; only Thumbnails is implemented. Search results are paged individual matches with page/count context, rather than the reference's page-group hierarchy. The overview is navigation-only; page operations stay disabled while it is shown. These are disclosed gaps, not complete 1:1 fidelity.
