# Recreation parity and evidence

## Observed reference

The private primary-reference session observed PDF Expert 3.13.4 build 1177 with an authored three-page synthetic PDF on macOS 27.0.1. Captures established the dark reader chrome, compact top command rows, left thumbnail navigation, page overview, and right-side search result navigation. Highlight selection surfaced a sign-in gate before an annotation was created. Private screenshots/AX are intentionally excluded from this public source export.

## This implementation

The recreated source composes AppKit/PDFKit with the shared Paperwork Core. The reader, optional page-thumbnail sidebar, paged navigation-only overview, and paginated local search navigation are implemented. Result rows include a page number, per-page match count and selected-text snippet. Core-supported operations retain their original behavior and limits. The replica does not include vendor branding, upsell, trial/account flow, or services.

## Unverified and remaining

The 24 October 2026 source snapshot compiled, passed 36 tests, and produced a strict-signature local package. On macOS 27.0.1, exact executable `91780663410660d353e96c4950e0cbed32f74b89f5307723f111593c924622cd` opened the three-page fixture, navigated to page 2, searched for BRAVO, showed the navigation-only overview, and returned to the reader. In retained 25 October captures, the old executable showed no main-area overview cards. The previously built `de63…` candidate changed the overview to a flipped stack, but its overview showed only two page previews with page buttons clipped at the top; page 3 appeared in AX but not as a visible card. See private `native25-overview/old/04-exact-fixture-overview.jpg` and `native25-overview/new/07-exact-fixture-overview.jpg`.

The current source candidate uses an explicit flipped `OverviewCanvasView` as the scroll document, sizes that document from the current 24-page batch, and positions each fixed-size preview and page button at explicit native-point coordinates. This makes the document extent and top inset deterministic; changing the batch resets the horizontal origin. The three-page fixture canvas width is 522 points; a 24-page batch remains horizontally scrollable. This is a source-level layout correction only: no build or native verification has been run for it, and no visual fix is claimed. Parent review and a fair native capture at the current and minimum window sizes remain required. The exact source diff preserves the existing page buttons/tags, range controls, reader-return path, and shared core. Same-input comparison, VoiceOver/minimum-window/macOS 14 checks, and broader native feature acceptance remain unverified. Text selection markup creation, export/save, forms, OCR, dark/light appearance comparison and multi-document behavior remain unverified against the reference. The implementation intentionally has one active document and no fake multi-tab affordance. It does not yet provide the observed sidebar panes for Bookmarks, Outline, or Annotation Summary; only Thumbnails is implemented. Search results are shown as paged individual matches with page/count context, not the reference page-group hierarchy. The overview is navigation-only; page operations remain disabled while it is shown. Differences should be added here only with reproducible build identity and private evidence index references.
